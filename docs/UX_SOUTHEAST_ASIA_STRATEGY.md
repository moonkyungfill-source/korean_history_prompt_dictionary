## 1. 핵심 전제

### 왜 한국사 콘텐츠가 핵심인가

| 다른 서비스가 줄 수 있는 것 | 우리만 줄 수 있는 것 |
|---------------------------|-------------------|
| AI 이미지 생성 (Midjourney, DALL-E) | **역사적으로 정확한 큐레이션 프롬프트** |
| 프롬프트 마켓플레이스 (PromptBase) | **시대별·카테고리별 체계적 한국사 콘텐츠** |
| K-culture 이미지 (Pinterest, Google) | **프롬프트 → 이미지 원클릭 생성 통합 경험** |
| 한국사 텍스트 정보 (Wikipedia) | **시각적·인터랙티브 한국사 탐험** |

**결론:** 사용자가 이 서비스에 오는 이유는 "AI 이미지 생성"이 아니라 **"한국사를 시각적으로 경험하는 것"**이다. AI 이미지 생성은 그 경험을 완성하는 도구다.

### 동남아 시장이 특별한 이유

- **인구 7억, 60%가 35세 미만** — 디지털 네이티브 세대
- **한류 호감도:** 인도네시아 86.5%, 태국 82.7%, 베트남 76.3%
- **K-드라마 시청률:** 동남아 20~49세 도시 시민의 91%가 한국 드라마 시청
- **한국어 학습률:** 인도네시아 43.8%, 필리핀 45.4%
- **소셜미디어 침투율 61.5%** — 콘텐츠 바이럴 기반
- **한국사 교육 콘텐츠의 글로벌 선례가 없음** — 블루오션

### 한국-동남아 역사적 접점 (콘텐츠 차별화 무기)

| 국가 | 역사적 접점 | 콘텐츠 가능성 |
|------|-----------|-------------|
| **베트남** | 리왕조 → 고려 귀화 (화산 이씨, 1224년), 베트남 왕자 이용상이 고려에서 몽골군 격퇴에 공헌 | "두 나라를 지킨 베트남 왕자" 스토리 컬렉션 |
| **태국** | 아유타야 왕조 → 조선 사신 교환 (1393년), 활발한 동서 교역 | "동양의 베네치아와 조선의 만남" 컬렉션 |
| **인도네시아** | 자와 왕국 사신 → 조선 방문 (1394, 1406, 1412년 기록), 허황옥 전설 | "바다를 건넌 교류의 역사" 컬렉션 |

→ 이 접점들은 동남아 사용자에게 **"한국사가 내 역사와도 연결된다"**는 감정적 연결을 만들어주는 핵심 콘텐츠 자산이다.

## 2. 동남아 타겟 페르소나

### 페르소나 A: "Linh" — 베트남 대학생, 한국어 학습자

| 항목 | 내용 |
|------|------|
| **나이** | 22세 |
| **위치** | 호치민, 베트남 |
| **직업** | 외국어대 한국어학과 3학년 |
| **기기** | 안드로이드 스마트폰 (주력), 노트북 (부) |
| **한국어** | 중급 (TOPIK 3급), 한국 드라마로 학습 |

**동기:**
한국어 수업에서 한국 역사 발표 과제가 자주 나온다. 텍스트 자료는 많지만 시각 자료가 부족해서, AI로 역사 장면을 생성해 발표에 활용하고 싶다. 특히 베트남-한국 교류사에 관심이 많아 화산 이씨 관련 이미지를 만들고 싶다.

**핵심 니즈:**
- 한국사를 **시대순으로 체계적으로 탐색**하고 싶음
- 각 시대의 **역사적 배경 설명**이 베트남어로 있으면 좋겠음
- 생성한 이미지를 **발표 자료에 바로 사용**하고 싶음
- **베트남-한국 교류사** 관련 프롬프트를 따로 찾고 싶음

**현재 블로커:**
- 프롬프트 목록이 평면적 — 어디서부터 봐야 할지 모름
- 역사적 맥락 설명이 없음 — 프롬프트 텍스트만으로는 이 이미지가 왜 중요한지 모름
- 결제: 베트남에서 토스페이먼츠 사용 불가 (해외카드/PayPal 미활성)

**이상적 경험:**
```
홈 진입 → "베트남어" 자동 감지 → 베트남-한국 교류 특집 배너 보임
→ "두 나라를 이은 왕자" 스토리 클릭 → 화산 이씨 관련 프롬프트 3개
→ 역사 배경 읽기 → 이미지 생성 → 발표에 사용 → SNS 공유
```

| 항목 | 내용 |
|------|------|

| **위치** | 방콕, 태국 |
| **직업** | TikTok/Instagram 크리에이터 (8만 팔로워, K-culture 채널) |
| **기기** | iPhone 15, MacBook |
| **한국어** | 초급, 영어 중급 |

**동기:**
K-드라마 리뷰 콘텐츠를 만들다가 "실제 역사는 어떠했을까?" 시리즈를 기획 중. 드라마와 실제 역사의 차이를 보여주는 비교 콘텐츠에 AI 생성 이미지를 활용하고 싶다. 조선 시대 궁궐, 전쟁 장면, 한복 등의 이미지가 필요하다.

**핵심 니즈:**
- **K-드라마 에피소드와 연결된 역사 프롬프트**를 찾고 싶음
- **대량으로** 이미지를 생성해야 함 (에피소드당 3~5장)
- 이미지에 **워터마크/크레딧 표시**가 있으면 자연 홍보 효과
- **시리즈/컬렉션** 단위로 프롬프트를 묶어서 보고 싶음

**현재 블로커:**
- 프롬프트가 단건 나열 — "거북선" 하나 찍고 끝, 연관 프롬프트 추천 없음
- 컬렉션/테마 기능 없음
- 태국어 UI는 있지만 역사 맥락 설명이 없어 어떤 프롬프트가 적합한지 판단 불가

**이상적 경험:**
```
"조선 시대" 컬렉션 진입 → 궁궐/인물/전쟁/생활 테마 보임
→ "임진왜란" 테마 클릭 → 관련 프롬프트 8개 (거북선, 이순신, 전투 등)
→ 각 프롬프트에 "이 장면의 역사" 1문단 설명
→ 5개 이미지 연속 생성 → 다운로드 → TikTok에 "역사 vs 드라마" 시리즈 업로드
```

**동기:**
세계사 수업에서 동아시아 단원을 가르칠 때 시각 자료가 부족하다. 교과서 삽화는 작고 오래되었다. AI로 생생한 역사 이미지를 만들어 수업에 쓰고 싶다. 학생들이 인도네시아-한국 교류사에 관심을 가지면 좋겠다.

**핵심 니즈:**
- **시대별 역사 타임라인**으로 체계적 탐색
- 각 프롬프트에 **교육용 역사 설명** (수업에서 그대로 인용 가능한 수준)
- **인도네시아어** 지원 (현재 id 로케일 존재)
- **저렴한 가격** — 교사 개인 비용으로 지불

**현재 블로커:**
- 교육적 맥락 없음 — 이미지 생성 도구일 뿐, 교육 도구가 아님
- 시대 순서가 아닌 사용횟수 순 정렬 — 교과 과정과 맞지 않음
- 결제 수단 부재

**이상적 경험:**
```
"시대별 탐험" 진입 → 타임라인 UI (선사 → 고조선 → 삼국 → ... → 현대)
→ "삼국시대" 클릭 → 역사 개요 + 관련 프롬프트 목록
→ 프롬프트마다 "역사적 배경" 박스 → 이미지 생성
→ "수업 자료 다운로드" → 이미지 + 설명 텍스트 PDF 패키지
```

## 3. 한국사 콘텐츠 전략

### 3-1. 콘텐츠 구조 재설계: "평면 목록" → "스토리 기반 탐험"

**현재 구조 (문제점):**
```
홈 → [프롬프트 목록] → 프롬프트 상세 → 이미지 생성
        ↑ 필터: 시대/카테고리
        ↑ 정렬: 사용횟수순
```
→ 사용자가 "무엇을 봐야 할지" 모르는 상태에서 25개 프롬프트를 필터링하는 구조. 역사적 맥락 없이 이미지 생성 도구에 그침.

**제안 구조 (콘텐츠 중심):**
```
홈 → [스토리 컬렉션] → 스토리 상세 (역사 배경 + 프롬프트들) → 이미지 생성
  ├→ [시대별 타임라인] → 시대 개요 + 프롬프트들
  ├→ [테마별 탐험] → 건축/인물/전쟁/생활 → 시대 횡단 비교
  └→ [프롬프트 사전] → 기존 필터 목록 (파워유저용)
```

### 3-2. 스토리 컬렉션 (신규 콘텐츠 타입)

스토리 컬렉션은 3~8개 프롬프트를 **역사적 서사**로 묶은 큐레이션 단위다.

**동남아 타겟 초기 컬렉션 제안:**

| # | 컬렉션 | 포함 프롬프트 | 동남아 연관성 |
|---|--------|-------------|-------------|
| 1 | **두 나라를 이은 왕자** | 리왕조 궁궐, 이용상의 항해, 고려 귀화, 몽골군 격퇴 | 베트남 사용자 — "우리 왕자가 한국에서 영웅이 되었다" |
| 2 | **바다를 건넌 사신들** | 자와 왕국 사신 조선 도착, 아유타야-조선 교역, 해상 무역로 | 인도네시아/태국 — "우리 조상이 한국과 교류했다" |
| 3 | **거북선과 이순신** | 거북선 설계, 명량해전, 이순신 초상, 한산도 대첩 | 전체 — K-드라마 '불멸의 이순신' 연결 |
| 4 | **한글의 탄생** | 세종대왕 집현전, 한글 창제, 훈민정음 반포 | 전체 — 한국어 학습자의 역사적 호기심 |
| 5 | **궁궐의 사계절** | 경복궁 봄/여름/가을/겨울, 창덕궁 비원 | 전체 — 비주얼 임팩트 최고, SNS 공유용 |
| 6 | **삼국의 영웅들** | 광개토대왕, 을지문덕, 김유신, 계백 | 전체 — 영웅 서사의 보편적 매력 |
| 7 | **조선의 하루** | 양반 일상, 시장 풍경, 서당, 과거 시험 | 전체 — 생활사 호기심, K-드라마 배경 |
| 8 | **독립의 함성** | 3.1운동, 안중근, 윤봉길, 독립군 | 전체 — 보편적 독립운동 서사 |

**컬렉션 데이터 구조 (Firestore):**
```
collections/{id}
├── title: { ko, en, vi, th, id, ja, zh }
├── description: { ko, en, vi, th, id, ja, zh }
├── historicalContext: { ko, en, vi, th, id, ja, zh }  // 300자 역사 배경
├── coverImageUrl: string
├── promptIds: string[]  // 3~8개
├── tags: string[]
├── targetRegions: string[]  // ["SEA", "ALL"]
├── relatedDramas: string[]  // ["미스터 션샤인", "불멸의 이순신"]
├── sortOrder: number
├── status: "published" | "draft"
└── createdAt: Timestamp
```

### 3-3. 프롬프트 단위 콘텐츠 강화

**현재:** 프롬프트 = 제목 + 프롬프트 텍스트 + 태그
**제안:** 프롬프트 = 제목 + **역사적 배경** + 프롬프트 텍스트 + 태그 + **관련 프롬프트**

**추가 필드:**
```
prompts/{id}
├── (기존 필드 유지)
├── historicalContext: { ko, en, vi, th, id, ja, zh }  // 신규: 1~2문단 역사 설명
├── relatedPromptIds: string[]  // 신규: 연관 프롬프트 3~5개
├── collectionIds: string[]  // 신규: 소속 컬렉션
├── relatedDramas: string[]  // 신규: 관련 K-드라마
└── difficulty: "beginner" | "intermediate" | "advanced"  // 기존 미사용 → 활성화
```

### 3-4. 시대별 타임라인 콘텐츠

각 시대(Era)에 개요 콘텐츠를 추가한다.

**시대별 개요 데이터:**
```
eras/{eraKey}
├── title: { ko, en, vi, th, id, ja, zh }
├── period: string  // "BC 2333 ~ BC 108"
├── summary: { ko, en, vi, th, id, ja, zh }  // 2~3문단 개요
├── keyEvents: [{ year: string, event: { ko, en, ... } }]
├── coverImageUrl: string
├── relatedRegions: string[]  // 동남아 연결점 태그
└── promptCount: number  // 해당 시대 프롬프트 수
```

  [◯] 한산도 대첩

## 8. 우선순위 로드맵

### Phase 1: 콘텐츠 기반 구축 (2~3주)

**목표:** 한국사 콘텐츠의 깊이를 만들어 "단순 도구" → "콘텐츠 플랫폼"으로 전환

```
Week 1:
  □ 기존 25개 프롬프트에 historicalContext 필드 추가 (7개 언어)
  □ 프롬프트 상세 페이지에 "역사적 배경" 섹션 UI 추가
  □ 관련 프롬프트 추천 (relatedPromptIds) 데이터 입력 + UI
  □ isFeatured / difficulty 필드 UI 활성화

Week 2:
  □ 컬렉션 데이터 모델 설계 + Firestore 스키마
  □ 초기 8개 컬렉션 콘텐츠 작성 (한국어 원본)
  □ 컬렉션 목록/상세 페이지 구현
  □ 동남아 교류사 프롬프트 10개 신규 작성

Week 3:
  □ 컬렉션 콘텐츠 7개 언어 번역
  □ 홈페이지에 컬렉션 섹션 추가
  □ targetRegions 기반 동남아 사용자 특집 배너 로직
  □ 가입 보너스 5 → 10크레딧 변경
```

### Phase 2: 결제 + 탐험 경험 (2주)

**목표:** 해외 결제 장벽 해소 + 콘텐츠 탐험 동기 부여

```
Week 4:
  □ 토스페이먼츠 해외카드 + PayPal 연동 (심사 통과 전제)
  □ $0.49 소액 패키지 추가
  □ 시대별 타임라인 페이지 구현 (/eras)
  □ 시대별 개요 콘텐츠 작성 + 번역

Week 5:
  □ SNS 공유 버튼 (Facebook, TikTok, Twitter, 링크 복사)
  □ 생성 이미지 공유용 OG 메타 태그
  □ 이미지 하단 서비스 브랜딩 (선택적 워터마크)
  □ 온보딩 관심사 선택 화면 구현
```

### Phase 3: 인게이지먼트 루프 (2주)

**목표:** 재방문 + 바이럴 메커니즘

```
Week 6:
  □ 시대 탐험 진행률 (대시보드)
  □ 컬렉션 완료 보상 시스템
  □ 프롬프트 목록 정렬 옵션 추가 (시대순, 난이도순)
  □ 대시보드 "추천 컬렉션" 섹션

Week 7:
  □ 레퍼럴 시스템 (친구 초대 → 양쪽 크레딧)
  □ 공유 인센티브 (첫 SNS 공유 → +2 크레딧)
  □ 동남아 타겟 마케팅 시작 (TikTok/Facebook)
  □ 성과 측정 + 피드백 수집 → 이터레이션
```
