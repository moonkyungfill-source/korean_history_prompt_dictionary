## 1단계: 페르소나

### 한국사 학습에서 학습자가 겪는 핵심 어려움

한국사는 동남아 학습자에게 다음과 같은 고유한 장벽이 존재한다:

| 장벽 유형 | 구체적 문제 |
|-----------|-----------|
| **언어 장벽** | 한국어는 Category IV 난이도(~2,200시간 필요). 역사 용어의 50~60%가 한자어(漢字語)로, 한글 습득만으로는 역사 텍스트 이해 불가 |
| **맥락 부재** | 고조선→삼국→고려→조선의 시간 흐름을 모르면 개별 사건이 "파편화된 사실"로만 인식됨 |
| **교재 부족** | 한국사 교재는 한국어/영어 중심. 베트남어, 태국어, 인도네시아어 번역본 극히 희소 |
| **문화적 거리** | 유교적 정치 체계(양반, 과거제), 왕조 교체 원리 등이 동남아 역사 경험과 다름 |
| **혼란 유발** | 사극 드라마로 얻은 역사 지식이 사실과 허구가 혼재되어 학습 기반이 불안정 |

### 페르소나 A: 린 (Linh) — 베트남 대학생, K-드라마 입문자

```
이름: Nguyễn Thị Linh (린)
나이: 22세
위치: 호치민, 베트남
직업: 대학교 3학년 (국제관계학)
한국어 수준: TOPIK 3급 (중급)
한국사 수준: 기초 (사극 드라마 경유)
디바이스: 스마트폰(주), 노트북(보조)
월 디지털 지출: 50,000~100,000 VND ($2~4)
```

**배경 스토리**:
린은 K-드라마 《이산》을 보고 조선 왕실에 관심을 가지게 되었다. 한국어를 TOPIK 3급까지 독학했지만, 역사 용어가 나오면 막힌다. "정조"가 왜 위대한 왕인지, 그가 어떤 시대적 맥락에서 개혁을 추진했는지 이해하고 싶지만, 한국어 역사 교재는 너무 어렵고 영어 교재는 건조하다. **베트남 화산 이씨(Lý Long Tường)의 후손**이라는 사실은 모르고 있다.

**핵심 니즈**:
- 드라마에서 본 장면의 실제 역사적 배경을 알고 싶다
- 한국사 시대 흐름을 베트남어로 이해하고 싶다
- 대학 발표에 쓸 수 있는 시각 자료가 필요하다
- TOPIK 고급 준비를 위해 역사 어휘력을 키우고 싶다

**좌절 포인트**:
- "이 사건이 왜 일어났는지" 원인을 알 수 없다
- 한자어 역사 용어를 번역기에 돌려도 뜻이 와닿지 않는다
- 시대순 정리가 안 돼서 고려와 조선이 뒤섞인다
- 결제가 한국 전용이라 유료 서비스를 쓸 수 없다

**기술 행동 패턴**:
- MoMo 전자지갑 사용, 월 소액 지출 선호
- TikTok/YouTube에서 K-컨텐츠 소비 (하루 2시간+)
- Zalo 메신저로 한국어 스터디 그룹 참여
- 인스타그램에 K-컨텐츠 감상 공유

### 페르소나 B: 프래우 (Praew) — 태국 TikTok 크리에이터

```
이름: Praewpailin (프래우)
나이: 28세
위치: 방콕, 태국
직업: K-컨텐츠 TikTok 크리에이터 (80K 팔로워)
한국어 수준: TOPIK 2급 (초급)
한국사 수준: 입문 (BTS/드라마 팬 경유)
디바이스: iPhone 15 (주), MacBook Air (편집)
월 디지털 지출: 300~500 THB ($8~14)
```

**배경 스토리**:
프래우는 K-pop 팬 영상으로 TikTok을 시작했고, 점차 한국 문화 전반으로 콘텐츠를 확장하고 있다. 최근 사극 드라마 클립이 높은 조회수를 기록하면서 한국사 관련 콘텐츠에 관심이 생겼다. 그러나 **역사적 사실을 정확하게 전달할 자신이 없다**. 아유타야와 조선의 교류사를 알게 되면 팔로워에게 엄청난 반응을 얻을 수 있을 것 같다.

**핵심 니즈**:
- 정확하면서도 재미있는 한국사 콘텐츠 소스가 필요하다
- AI 생성 역사 이미지로 TikTok 영상 퀄리티를 높이고 싶다
- 태국-한국 교류사를 발견하여 차별화된 콘텐츠를 만들고 싶다
- 팔로워가 "와, 이거 몰랐다!" 할 만한 역사적 사실을 찾고 싶다

**좌절 포인트**:
- 한국사 정보의 정확성을 검증할 수 없다 (사극 vs 사실)
- 역사 이미지를 직접 만들 능력이 없다
- 역사적 맥락 없이 파편적 사실만 알고 있다
- 한국어를 잘 모르니 한국어 서비스 이용이 제한적이다

**기술 행동 패턴**:
- PromptPay/TrueMoney로 소액 결제
- TikTok + Instagram Reels 하루 4시간+ 활동
- Canva/CapCut으로 콘텐츠 제작
- LINE 그룹에서 K-pop 팬 커뮤니티 활동

### 페르소나 C: 안디 (Andi) — 인도네시아 고교 교사

```
이름: Andi Wijaya (안디)
나이: 35세
위치: 자카르타, 인도네시아
직업: 고등학교 세계사 교사 (7년차)
한국어 수준: 없음 (영어 중급)
한국사 수준: 기초 (교과서 수준)
디바이스: Android 스마트폰, 학교 PC
월 디지털 지출: 50,000~100,000 IDR ($3~6)
```

**배경 스토리**:
안디는 세계사 수업에서 동아시아 역사를 가르치는데, 학생들이 한류의 영향으로 한국사에 특별한 관심을 보인다. 교과서의 한국사 내용은 한국전쟁 2페이지뿐이고, 학생들의 질문에 제대로 답하지 못한다. **수업에 시각 자료를 활용하고 싶지만** 저작권 걱정 없이 쓸 수 있는 역사 이미지가 없다. 자와 왕국과 조선의 교류사를 알면 수업이 훨씬 풍부해질 것이다.

**핵심 니즈**:
- 수업에 바로 활용할 수 있는 한국사 시각 자료가 필요하다
- 학생 수준(고등학생)에 맞는 한국사 설명이 필요하다
- 인도네시아어로 된 역사적 배경 설명이 있으면 이상적이다
- 인도네시아-한국 교류사를 발견하여 수업에 연결하고 싶다

**좌절 포인트**:
- 한국어를 전혀 모른다 — 한국어 전용 서비스는 진입 불가
- 교육용 이미지 저작권이 항상 걱정된다
- 학생 수준에 맞게 내용을 조절하기 어렵다
- 한국사 시대 흐름을 간결하게 정리한 자료가 없다

**기술 행동 패턴**:
- GoPay/OVO 전자지갑, 소액 결제 선호
- YouTube에서 교육 콘텐츠 시청 (Khan Academy 등)
- WhatsApp 교사 커뮤니티에서 자료 공유
- Google Classroom으로 수업 운영

- AI 이미지 생성 도구는 많지만, 한국사 전문 프롬프트는 없다
- 결제 수단이 한국 전용이라 유료 기능 이용 불가
- 생성한 이미지의 역사적 정확성을 검증하기 어렵다

**기술 행동 패턴**:
- MoMo/VNPay로 결제
- Behance/Pinterest에서 레퍼런스 수집
- Adobe Creative Suite + Midjourney 사용 경험 있음
- Facebook 한국어 학습 그룹 활동

#### Stage 1: 발견 (Discovery) — 감정: 기대 😊

| 항목 | 내용 |
|------|------|
| **행동** | TikTok에서 한국사 관련 영상 발견 → 서비스 링크 클릭 |
| **생각** | "한국사를 이미지로 체험할 수 있다고? 재밌겠다!" |
| **접점** | TikTok 영상, Instagram 포스트, 한국어 스터디 그룹 공유 링크 |
| **기대** | 베트남어로 한국사를 쉽게 이해하면서 이미지도 만들 수 있을 것 |

#### Stage 2: 첫 방문 (First Visit) — 감정: 보통 😐

| 항목 | 내용 |
|------|------|
| **행동** | 홈페이지 접속 → 로케일 자동 감지(vi) → 프롬프트 목록 탐색 |
| **생각** | "오, 베트남어가 되네! 근데 이 프롬프트들이 뭔지 맥락을 모르겠다" |
| **접점** | 홈페이지, 프롬프트 목록, 시대 필터 |
| **기대** | 각 프롬프트의 역사적 배경을 베트남어로 읽고 싶다 |
| **⚠️ 이탈 위험** | 프롬프트 제목만 보이고 역사적 맥락이 없으면 "뭔지 모르겠다"로 이탈 |

#### Stage 3: 학습 시도 (Learning Attempt) — 감정: 불안 😰

| 항목 | 내용 |
|------|------|
| **행동** | 프롬프트 상세 페이지 진입 → 역사적 배경 읽기 → "원인→사건→결과" 파악 시도 |
| **생각** | "이 사건이 왜 일어났는지 연결이 안 된다. 이전 시대를 먼저 봐야 하나?" |
| **접점** | 프롬프트 상세, 시대별 타임라인, 관련 프롬프트 추천 |
| **기대** | "이전 사건"→"이 사건"→"이후 사건"의 인과 연결을 따라가고 싶다 |
| **⚠️ 이탈 위험** | **시대순 연결이 없으면** 파편적 사실로만 느껴져 학습 포기 |

#### Stage 4: 이미지 생성 시도 (Generation Attempt) — 감정: 좌절 😤

| 항목 | 내용 |
|------|------|
| **행동** | 회원가입 → 이미지 생성 버튼 → 크레딧 필요 → 결제 시도 |
| **생각** | "결제를 하고 싶은데... Toss Payments? 이거 한국 전용인데?" |
| **접점** | 회원가입, 크레딧 구매, 결제 위젯 |
| **기대** | MoMo나 국제 카드로 결제하고 싶다 |
| **🔴 이탈 포인트** | **결제 불가 = 서비스 가치 체험 불가 = 확정 이탈** |

#### Stage 5: 이탈 또는 제한적 사용 (Drop-off / Limited Use) — 감정: 실망 😢

| 항목 | 내용 |

## 3단계: 친화도법

여정지도에서 수집된 경험 데이터를 패턴별로 분류하여 핵심 인사이트를 도출한다.

### 클러스터 1: "연결이 안 된다" — 맥락 부재의 고통

**수집된 경험 패턴:**
- "이 사건이 왜 일어났는지 모르겠다" (린)
- "이전 시대를 먼저 봐야 하나?" (린)
- "정보가 정확한 건지 모르겠다" (프래우)
- "교과서에 한국전쟁 2페이지뿐이다" (안디)
- "사극에서 본 것과 실제가 뒤섞인다" (프래우)
- "고려와 조선이 헷갈린다" (린)

**핵심 인사이트 (Insight #1):**
> **한국사의 시간적 흐름과 인과적 맥락이 UX 구조에 내재되어 있지 않으면, 학습자는 "고립된 사실의 나열"로 인식하고 학습을 포기한다.**

**해결 방향:**
- 모든 콘텐츠에 시대 위치 표시 (타임라인 바)
- "이전 사건 → 이 사건 → 이후 사건" 인과 연결 필수
- 시대순 정렬이 기본 (인기순/최신순 아님)

---

### 클러스터 2: "쓸 수가 없다" — 접근성 장벽

**수집된 경험 패턴:**
- "결제가 한국 전용이다" (린, 프래우, 안디, 마이)
- "한국어를 모르니 서비스를 쓸 수 없다" (안디)
- "한자어 역사 용어가 번역이 안 된다" (린)
- "모바일에서 메뉴가 안 보인다" (린, 프래우)
- "학교 예산으로 결제가 안 된다" (안디)

**핵심 인사이트 (Insight #2):**
> **동남아 사용자는 "관심은 있지만 접근할 수 없는" 상태다. 결제 수단, 언어, 디바이스 3중 장벽이 동시에 작용하여 서비스 가치를 체험하기도 전에 이탈한다.**

**해결 방향:**
- 가입 시 무료 크레딧 5~10개 제공 (가치 체험 선행)
- 국제 결제 수단 (Stripe, PayPal 우선 + 현지 전자지갑 장기)
- 모바일 네비게이션 완전 구현
- 역사 용어 글로서리 (한국어 → 현지어 대응 사전)

---

### 클러스터 3: "나와 관련이 없다" — 정서적 거리

**수집된 경험 패턴:**
- "한국사가 나와 무슨 상관이지?" (안디, 잠재 이탈자)
- "베트남 화산 이씨를 모른다" (린)
- "아유타야와 조선 교류를 모른다" (프래우)
- "자와 왕국과 조선의 사신 교류를 모른다" (안디)
- "내 나라 역사와 연결되면 완전 다른 느낌일 텐데" (모든 페르소나)

**핵심 인사이트 (Insight #3):**
> **"내 나라의 역사와 한국사가 연결된다"는 발견 순간이 정서적 전환점(Aha moment)이다. 이 연결이 없으면 한국사는 "남의 나라 이야기"로 남고, 연결이 있으면 "우리가 함께 만든 역사"가 된다.**

**해결 방향:**
- 지역별 교류사 컬렉션을 최초 진입점에 배치
- 사용자 국가 자동 감지 → 관련 교류사 우선 표시
- "한국-베트남", "한국-태국", "한국-인도네시아" 교류사 스토리 라인

---

### 클러스터 4: "수준이 안 맞다" — 레벨 불일치

**수집된 경험 패턴:**
- "역사 교재가 너무 어렵다" (린)
- "학생 수준에 맞출 수 없다" (안디)
- "정확성을 검증할 수 없다" (프래우)
- "체계적으로 비교할 수 없다" (마이)
- "TOPIK 준비에는 도움이 안 된다" (린)

**핵심 인사이트 (Insight #4):**
> **동일한 역사적 사건이라도 학습자 수준에 따라 전혀 다른 깊이의 설명이 필요하다. 한 가지 수준의 콘텐츠만 제공하면, 초보자는 "어렵다"고 느끼고 전문가는 "얕다"고 느껴 양쪽 모두 이탈한다.**

**해결 방향:**
- 3단계 수준별 설명 (기초 2줄 / 중급 1문단 / 심화 2~3문단)
- 난이도 배지 표시 (별 1~3개)
- 학습자 수준 선택 온보딩 → 맞춤 콘텐츠 필터링

---

### 클러스터 5: "공유하고 싶다" — 바이럴 욕구

**수집된 경험 패턴:**
- "TikTok 영상에 쓰면 대박이겠다" (프래우)
- "대학 발표에 쓰고 싶다" (린)
- "수업에 활용하고 싶다" (안디)
- "디자인 레퍼런스로 쓰고 싶다" (마이)
- "생성한 이미지를 자랑하고 싶다" (모든 페르소나)

**핵심 인사이트 (Insight #5):**
> **AI 이미지 생성은 "소비"가 아닌 "창작"이다. 학습자가 생성한 이미지를 자연스럽게 공유할 수 있는 경로가 있으면, 이것이 곧 마케팅 채널이 된다. 특히 크리에이터(프래우)와 교사(안디)는 공유 행위 자체가 서비스 목적과 일치한다.**

**해결 방향:**
- 이미지 생성 후 즉시 SNS 공유 버튼 (TikTok, Instagram, Facebook)
- 공유 이미지에 서비스 워터마크 + 역사 정보 오버레이
- 공유 시 보너스 크레딧 지급
- 교사용 "수업 자료 다운로드" 패키지

## 앱 반영 제안

### 즉시 반영 (P0 — 접근성 + 맥락)

#### 1. 프롬프트 목록 기본 정렬: 시대순

**현재**: 프롬프트 목록이 필터 없이 전체 표시
**변경**: 기본 정렬을 시대순으로 변경 (선사→고조선→삼국→...→현대)

**적용 파일**: `src/components/prompts/PromptList.tsx`

#### 2. 프롬프트 상세: "이전/이후 시대" 연결

**현재**: 프롬프트 상세 페이지에 단일 콘텐츠만 표시
**변경**: 페이지 하단에 "이전 시대 프롬프트" / "이후 시대 프롬프트" 네비게이션 추가

**적용 파일**: `src/app/[locale]/prompts/[id]/page.tsx`

#### 3. 시대 위치 표시 바

**현재**: 프롬프트에 시대가 텍스트로만 표시
**변경**: 모든 프롬프트 상세 페이지 상단에 10개 시대 타임라인 바 표시, 현재 시대 하이라이트

**신규 컴포넌트**: `src/components/prompts/EraTimeline.tsx`

#### 4. 가입 시 무료 크레딧

**현재**: 가입 후 크레딧 0
**변경**: 가입 시 5 크레딧 자동 지급

**적용 파일**: `src/app/api/auth/create-user/route.ts`

#### 5. 모바일 네비게이션

**현재**: 768px 미만에서 네비게이션이 숨겨짐 (hidden)
**변경**: 햄버거 메뉴 + 슬라이드 네비게이션 구현

**적용 파일**: `src/components/common/Header.tsx`

### 단기 반영 (P1 — 교류사 + 수준별)

#### 6. 국가별 교류사 컬렉션

**현재**: 컬렉션 데이터 모델만 존재 (UI 없음)
**변경**: 홈페이지에 "당신의 나라와 한국의 역사" 섹션 추가 (로케일 감지 기반)

**적용 파일**: `src/app/[locale]/page.tsx`, 신규 `src/components/home/ExchangeHistory.tsx`

#### 7. 수준별 콘텐츠 토글

**현재**: 콘텐츠 수준 구분 없음
**변경**: 프롬프트 상세 페이지에 "기초 / 중급 / 심화" 탭으로 역사적 배경 깊이 조절

**적용 파일**: `src/app/[locale]/prompts/[id]/page.tsx`

#### 8. 역사 용어 글로서리 팝오버

**현재**: 역사 용어 설명 없음
**변경**: 역사적 배경 텍스트 내 한자어/전문용어에 툴팁 팝오버 (현지어 의미 + 한국어 원문)

**신규 컴포넌트**: `src/components/common/HistoryTermTooltip.tsx`

### 중기 반영 (P2 — 바이럴 + 게이미피케이션)

#### 9. SNS 공유 기능

이미지 생성 후 원클릭 공유 (서비스 워터마크 + 역사 정보 오버레이)

#### 10. 시대 탐험 진행률

대시보드에 10개 시대 탐험 진행률 표시 + 완료 보상

#### 11. 공유 보너스 크레딧

이미지 공유 시 0.5 크레딧 지급 (일일 상한 2개)
